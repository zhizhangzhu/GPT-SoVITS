# 本地语音工作台

界面采用任务列表、操作工作区和详情面板的布局，参考 ClearML 的信息分层方式。继续使用项目现有的 Gradio 组件与模型流程。

## 导航

- **数据集**：创建自动处理任务，试听、校对、筛选训练片段。已有素材和标注可使用“手动预处理工具”。
- **TTS 训练**：设置实验与模型版本，先做数据格式化，再训练 SoVITS 和 GPT。
- **TTS 推理**：在当前工作台选择并加载模型、上传参考音频、填写目标文本并生成语音，无需另外打开 9872 页面。
- **So-VITS-SVC**：歌手素材归档、切片试听审核、专属模型训练与完整音轨转换。详见 [SVC 使用说明](../SVC使用说明.md)。

## 模型与工具调用

TTS 推理页的“使用已有参考音频或快照”可直接选择 `ref_audios/` 中已有的参考音频，也可恢复已保存的参考设置快照。“保存新快照”是独立区域，只有主动点击保存才会留存当前设置。快照会复制主参考音频、辅助参考音频，并保存参考文字、语种、免参考文本选项和所选 GPT/SoVITS 模型；目标生成文本不会保存。“参考设置快照”是整套输入预设，不是单独的音色模型。使用快照后若模型选择发生变化，还需点击“加载模型”。删除快照需要勾选确认，且不会清空当前表单。快照文件存放在被 Git 忽略的 `ref_audios/snapshots/`。

下载的 GPT-SoVITS v4 推理包若包含 GPT `.ckpt`、SoVITS `.pth` 和参考音频，可分别放入 `GPT_weights_v4/`、`SoVITS_weights_v4/` 和 `ref_audios/`。在 TTS 推理页点击“刷新”，选择这对模型并加载，再从“本机已有参考音频”选音频。SVC 模型导入区不识别 GPT-SoVITS 的 `.pth`。参考文字应按音频实际内容填写，不能只凭文件名推断。

- **TTS 数据集自动处理**：本地 UVR、切片器、SenseVoice 和 Whisper 处理音频；Codex CLI 规划切片参数并检查 ASR 标注。必须安装并登录 Codex CLI，模型沿用 CLI 配置，代码没有指定 GPT 版本。Codex 接收文件时长和标注数据，不直接试听音频。
- **TTS 训练与推理**：运行本地 GPT-SoVITS 模型。“GPT 模型”指本项目的语音语义模型，不代表调用 OpenAI GPT 服务。
- **SVC 数据集、训练与转换**：本地脚本和音频模型处理，没有 Codex CLI 或 OpenAI GPT 接口调用。首次缺少音频模型权重时仍可能下载文件。

## 数据集审核

1. 新建任务，上传同一说话人的音频并填写说话人名称。
2. 自动处理完成后，从左侧任务列表选择任务。
3. 在“音频审核”中试听片段，修正文字与语种，决定是否选入训练。
4. 保存草稿，或使用上一条、下一条、确认并下一条、排除并下一条继续审核。切换片段和任务时会保存当前修改。
5. 完成后点击“确认审核并送入训练”。系统生成 `train.list`，自动填写训练路径，并打开“数据格式化”。

搜索与筛选只影响展示，不会删掉其他片段。训练清单包含完整任务中选用的片段。

快捷键：`Alt + ← / →` 切换片段；`Ctrl + Enter`（macOS 为 `⌘ + Enter`）确认并下一条。

Codex 标注检查每 40 条为一个批次，验证结果后保存输入摘要与回执。失败或停止后重试，已完成且输入未变化的批次直接复用；文字、语种、质量标记或检查规则变化时重新执行对应批次。回执损坏时重新检查，不直接通过。缓存从此次改造后的批次开始生效，历史结果没有回执时仍需执行一次。脚本与 Codex CLI 的组合流程继续保留。

如果修改了已经确认的任务，原训练清单会备份为 `train.before-edit-*.list`，需要重新确认审核才能生成新的训练清单。此前已经启动的训练仍使用其原先读取的数据。

## 边界调整与手动工具

“任务详情与文件”中可以查看任务目录、下载标注文件、展开处理日志，以及打开标注编辑器进行拆分与合并。编辑器保存后，回到工作台点击“重新读取标注结果”，再确认审核。

## 外观与运行

顶部按钮可以切换深色或浅色，偏好保存在当前浏览器。字体使用系统字体，无需联网下载。较窄屏幕会将模块导航改成横向排列，将任务列表和详情面板放到上下布局。

主操作区限制最大内容宽度，避免超宽屏将表单和正文拉得过长。SVC 的歌手身份和任务状态位于工作区上方；训练、转换时在上方显示当前实验及检查点。歌词、边界修正和完整片段列表可按需展开。已结束的 SVC 任务停止自动轮询，点击“刷新列表”可重新读取。

主工作台的推理模型按需加载，可以点击“卸载模型”释放显存。更换模型、GPU 或标准／并行推理方式后，需要重新加载模型。停止生成会在当前计算片段结束后停止。
TTS 推理页在生成状态下方持续显示当前实际加载的 GPT 与 SoVITS 模型路径；左侧下拉选择改变但尚未重新加载时会明确提示。生成状态变化不会覆盖这份模型信息。

TTS 后台等待有超时保护。默认模型加载最多等待 600 秒；一次合成总时长上限为 3600 秒，连续 300 秒没有收到结果会停止；请求停止后最多等待 30 秒，未响应则终止推理进程。超时、后台退出或生成事件流被关闭时，会清理进程、模型配置临时文件及任务锁。已生成的音频文件保留，正常完成或成功响应停止时可以继续使用已加载模型。

慢速设备或较长文本可在启动服务前调整以下环境变量，单位均为秒，必须是有限正数：`GPT_SOVITS_TTS_LOAD_TIMEOUT`、`GPT_SOVITS_TTS_GENERATE_TIMEOUT`、`GPT_SOVITS_TTS_RESPONSE_TIMEOUT`、`GPT_SOVITS_TTS_CANCEL_TIMEOUT`。

TTS 数据集和推理的普通校验失败使用约 5 秒的通知，页面保留错误原因与已填写内容，不把关联组件替换为 Error。确认审核失败不会跳转到训练。数据集自动刷新读取失败时暂停轮询，可从任务列表重新选择任务恢复刷新。参考音频在提交推理前检查时长，时长不符合当前 3–10 秒要求时保留已加载模型；本次没有扩大参考音频上限。

数据集与 SVC 页面显示所在磁盘的可用空间，点击各自的刷新列表更新。上传归档、后台处理及 SVC 检查点保存前检查余量；默认保留 2 GiB，可通过启动环境变量 `GPT_SOVITS_DISK_RESERVE_GIB` 设置有限非负值。转换与训练还按音轨、快照、权重或待保存张量估算额外空间。检查是提前提示，不能为任务独占磁盘，首次下载模型等额外写入仍可能增加需求。

当前保留原始素材、已发布数据、实验快照、全部检查点与最新续训状态，不自动删除这些文件。磁盘不足时先释放空间再重试；SVC 从最近完整检查点继续，不保证保存尚未写出的训练步。

修改界面代码后，重启主 WebUI；已开启的人声分离和标注编辑器也需要重新启动各自的进程。独立推理脚本仍可单独使用，但主工作台不再启动第二个推理 WebUI。

## 仓库审查记录（2026-10-13）

本次重点审查主 WebUI、自动数据集、TTS 工作台和 SVC 的任务、模型加载与界面集成。以下结论来自代码、已有服务日志和页面查看，没有重新运行模型训练或音频质量评测。

### 已修正

- 日志中的空模型版本异常：模型版本回调先检查合法性，避免把 `None` 写入环境变量。
- SVC 任务进入完成、失败、停止或待审核状态后停止轮询；每次轮询只读取当前任务，不扫描完整任务历史。回收已退出的受管子进程记录。
- TTS 数据集日志仅读取文件尾部，避免每次刷新读取整份日志。
- 无法读取的 SVC 实验记录会记录后台警告并跳过，避免单个损坏记录影响实验列表和页面构建；源记录不删除。
- 提交 SVC 前检查 TTS 常驻推理进程，提示先卸载模型，减少显存叠加占用。
- 统一内容宽度、标题层级、间距与操作按钮尺寸；SVC 调整为素材设置和试听审核两栏，次要设置按需展开，模型选择和任务状态不再藏在其他标签页或页面底部。
- 修正文档中 SVC“尚未实现”的过时说明，明确哪些流程会调用 Codex。
- TTS 模型加载与合成增加截止时间、无响应超时和停止请求超时。轮询等待会识别后台退出或手动卸载；失败、超时和中断后清理后台及任务锁。
- 主 WebUI 的手动工具、音频切片、训练、特征提取、模型下载和 Windows 进程停止全部改为参数列表启动，移除 `shell=True` 命令拼接。标注编辑器使用其明确声明的 `--webui_port_subfix` 参数。
- SVC 数据整理逐块读取源音轨，保留低频能量曲线用于全局切点规划；转换逐块读写，拼接仅保留未完成的交叠尾部；混音分块处理并保持整体峰值归一化。浮点临时音轨自动清理，最终音轨写完后原子替换。
- Codex 标注检查按批次输入摘要复用结果，保存回执后再更新元数据，恢复时识别更新前与更新后的输入状态。完整验证批次编号、文字、语种与复核标记后再应用建议。
- 自动数据集与 SVC 增加磁盘余量提示及处理前、处理中的空间检查；SVC 保存检查点前估算整组张量大小，最新续训索引仍在整组文件成功写入后更新。
- TTS 数据集与推理的普通校验改为通知和页面状态；审核送入训练使用明确成功标记，失败时保留训练路径与当前页面。参考时长先在界面回调检查，避免无效输入导致后台模型被释放。
- TTS 数据集读取状态时回收已退出的受管子进程记录，降低长时间运行时的历史进程对象积累。
- SVC 候选切片增加原音轨切点上下文检查、附近停顿建议、风险排序和筛选；提供当前与推荐切点的短音频比较。一键应用时同步修改共用边界的相邻片段，保存修订并恢复待审核；过期建议不会覆盖新修订。全部使用本地工具。
- SVC 增加修订前后试听、可连续撤销的边界修改历史、确认／排除并下一条、快捷键、审核进度和位置恢复。
- SVC 按歌手记录采用、手动修改及不采用边界建议的反馈；仅使用试听确认且未撤销、未替换的标签生成可预览参数报告。多个源素材时保留独立源作比较，应用或重置参数需主动操作。
- SVC 试听缓存使用独立目录与访问记录，提供大小统计和按最近访问时间清理入口；当前试听、片段修订、已入库数据和训练文件不作为清理目标。
- SVC 训练页增加已审核入库数据的训练前报告：有声音高覆盖、片段长度、源素材时长占比、文件校验及可下载图表。CPU 使用所选训练 F0 工具，不加载训练模型；入库清单与文件变化时标记报告过期。
- SVC 报告改为可停止、可重试的后台任务，并展示逐片进度；训练集验证集按素材时长推荐且允许手动指定验证源。转换任务重试会校验并复用已完成的解码、分离阶段。
- SVC 报告提交做同歌手去重，已有相同数据与 F0 的完整报告会直接显示查看入口；训练页显示各源素材在训练/验证中的时长。检查点与转换缓存的大文件校验在后台逐块进行，可显示进度并响应停止请求。
- SVC 检查点列表只显示完整保存的 G/D/状态组；新检查点记录校验值。试听支持同位置 A/B 切换及播放响度匹配；旧检查点可以经确认手动清理，最新续训检查点受保护。
- SVC 训练按轮打乱片段并在检查点保存实际顺序和批次位置；固定验证片段最多三段，按源素材和音高分散选择，可用原声并排比较两个检查点。训练页优先显示检查点试听，数据报告按需展开。
- 数据报告新增异常片段清单和返回原任务试听的入口，提示低 F0 有声比例、范围边缘、频繁跳变、时长异常及校验失败。提示需要人工试听判断。
- 增加可控 WAV、真实 FFmpeg/F0 及实际 Gradio 回调的回归检查。修复校准报告中 NumPy 整数导致 JSON 保存失败的问题，确认连续撤销、共享切点样本覆盖、反馈失效和缓存保护行为。范围见 [SVC 回归验证](../SVC回归验证.md)。
