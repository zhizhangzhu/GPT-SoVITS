# So-VITS-SVC 工作区

## 安装与启动

在启动现有工作台的 Python 环境中执行：

```bash
python -m tools.svc.install
python webui.py zh_CN
```

安装器将 4.1-Stable 的提交 `730930d337d171479eadf305f96cbed4bb393e77` 安装到 `runtime/so-vits-svc`，创建 `runtime/svc-env`。独立环境复用主环境的 CUDA PyTorch，额外依赖安装到该环境，不按上游旧 requirements 降级主环境。需要 Git、FFmpeg、Python 3.10 和可用于训练的 CUDA GPU。

本次默认配置是 44.1 kHz、ContentVec 第 9 层 256 维 ONNX（4.1 后端的 4.0 兼容配置）、单目标歌手。ONNX 编码器在 CPU 运行，神经网络训练和转换使用选定 GPU。F0 支持 `dio`、`harvest`、`pm`，不需要另下载 F0 神经网络。可按素材对比选择，不承诺一种算法适合所有高音、气声或说话声。

模型下载支持分段续传，并对照 Hugging Face LFS SHA256 校验。失败后重新运行同一安装命令。`HF_ENDPOINT` 可指定兼容的下载入口。运行版本及模型来源、修订、校验值记录在 `runtime/svc-runtime.json` 和 `runtime/svc-assets/manifest.json`。

已启动的旧工作台进程需要重启才能显示新功能。代码变更不会自动重启你的服务器。

## 1. 素材整理

1. 进入主导航 **So-VITS-SVC**。展开“创建或重命名歌手”创建身份；后续素材选择相同身份。重名歌手仍是独立身份，可以重命名。
2. 在“素材与审核”批量上传音频，选择“干净人声”或“带伴奏的音乐”。混音使用现有 UVR5，保留与原音轨等长的伴奏。
3. 歌词可不提供。批量上传时，LRC 和音频的文件名主干应一致，例如 `歌曲A.flac` 与 `歌曲A.lrc`。粘贴歌词仅用于单份音频。支持重复时间戳和 `[offset:毫秒]`。
4. 如歌词相对音频整体偏移，在设置中填写额外偏移，正值表示延后。未匹配的歌词文件会提示错误；无有效时间戳的歌词会按停顿降级处理。
   设置中也可调整静音判定下限、静音及削波比例提示阈值；每条切片记录当时阈值，修正边界后沿用该阈值重新计算。
5. 点击“整理为候选切片”，在任务历史查看进度。处理完成后自动显示切片，也可点击“刷新列表”。

歌词时间戳用于寻找附近的停顿，**没有逐字歌词识别和强制对齐**。能量停顿也不等于可靠的歌声断句；连续演唱达到时长上限时，会产生需复核提示。首版没有把 ASR 置信度当成歌声校准结果。

## 2. 试听与入库

- 每片显示原音轨起止秒数、歌词辅助信息、质量指标与原因。播放器提供波形、片段循环播放和前后各一秒的上下文。
- 默认按风险优先显示待审核片段，可切换“时间顺序”。“高风险待审核”集中展示疑似截字、削波和不可直接入库片段；“有质量提示”便于检查时长、静音比例和音量问题。优先级文字同时出现在片段选择器与列表，排序不改变音轨时间或文件。
- 在“切点检查与推荐”查看起点与终点的状态、推荐时间和移动距离。展开“试听切点前后”，分别比较当前及推荐切点前后约一秒的音频；播放器标签标明切点在试听中的位置。没有推荐时隐藏对应推荐播放器，并禁用应用按钮。
- 点击“采用推荐切点并重新裁切”应用建议。若与相邻片段共用切点，会同步调整两侧，保持共同边界；受影响片段生成新修订、恢复待审核，并从未来训练清单中撤下，重新试听通过后入库。已创建实验的固定快照不受影响。
- 精确填写起止时间，点击“保存边界并重新裁切”。拆分位置同样以**原音轨时间**计。可合并同一素材的下一相邻片段；不能跨歌曲合并。
- 修改边界、拆分或合并后重新审核。近乎静音或不足 0.4 秒的片段不能直接通过，须先修正。
- 试听后“确认通过”，再“将已确认片段入库”。“确认无提示片段并入库”只批量确认工具检查通过且没有其他提示的待审核片段，不自动批准有疑点的片段。
- “确认并下一条”“排除并下一条”保存审核决定后，在当前筛选与顺序中继续找待审核片段，跳过已经审核的片段。进度显示已确认、已排除和待审核数量。上次试听位置保存在任务中，重新选择原任务时恢复；被当前筛选排除的旧位置会退到可见片段。
- 已排除和待审核片段不会用于训练。同一素材的重复上传会打开已有任务。任务重试保留已经处理完的素材及其审核记录。
- “导出歌手数据集”下载已审核 WAV 和清单；修改记录可在日志展开区下载。

指标包括时长、RMS、静音比例、峰值、削波比例、边界是否仍发声。它们不能确认歌手身份、多人和声、伴奏残留或分离质量；音乐分离素材始终需要试听确认。

### 边界建议与审核优先级

新整理的片段自动检查原人声音轨的切点上下文。采用约 20 毫秒能量帧，在当前切点附近 ±1.2 秒内寻找至少 120 毫秒的持续低能量停顿，沿用片段的静音阈值。推荐受源音轨范围、相邻片段位置和最短长度约束；没有合适停顿时保留原切点，不强行选一个音量较低的唱字。手动修改、拆分、合并和应用推荐后重新计算相关边界。

| 优先级 | 含义 |
| --- | --- |
| 不可直接入库 | 近乎静音或过短，先修正 |
| 优先复核 | 疑似截字、源素材已截断、削波或持续发声强制切分 |
| 需要检查 | 时长、静音占比、音量或停顿长度问题 |
| 试听确认 | 歌词定位、分离等一般提示 |
| 常规试听 | 当前信号检查未发现提示，仍可试听确认 |

这是信号规则的审核排序，不是经过校准的错误概率，也不做逐字歌词识别。历史任务按已有质量标记排序，选择片段时也会计算当前边界建议；重新裁切后保存新分析结果。应用前校验片段、相邻片段修订及源文件状态，建议过期时要求重新选择片段，避免覆盖后续修改。整套流程使用本地工具，不新增 Codex CLI 调用。

### 修订对比、撤销与快捷键

展开“修订对比与撤销”选择边界修改记录，分别试听修改前后的片段。拆分或合并记录包含多个片段，可通过两侧选择器逐个比较。历史音频保留原修订，重新裁切与恢复使用递增的新修订号，不覆盖旧版本。

“撤销最近一次边界修改”按当前任务的修改顺序回退，可连续撤销裁切、拆分、合并和采用推荐。恢复前检查当前片段是否仍匹配记录，并校验历史音频；不一致时停止恢复。恢复片段回到待审核状态，并撤下受影响片段的未来训练清单；已创建实验快照保留。恢复片段不在当前筛选内时切换到待复核。

快捷键仅在对应工作区可见时生效：

- `Ctrl / ⌘ + Enter`：确认并下一条。
- `Ctrl / ⌘ + Shift + Enter`：排除并下一条。
- `Alt + ← / →`：上一条／下一条。
- `Alt + Z`：撤销最近一次边界修改。

### 用真实审核反馈校准边界

1. “采用推荐”及“保存边界”记录当时的建议、上下文和实际切点；“不采用本次建议”可填写原因。
2. 采用或手动修正后，试听并确认通过；不采用建议后也要确认原片段。未确认、整片排除、已被替换或撤销的反馈不用于校准。批量确认无提示片段不当作已试听标签。
3. 在左侧“用审核反馈校准边界”点击“生成参数建议”。至少需要 5 个确认片段；多个源素材时按源划分保留组，校准组至少 3 个片段。每次最多使用最近 60 个有效片段，相同源素材与原边界去重，源文件变化的样本跳过。
4. 本地规则搜索附近范围、最短停顿和相对能量阈值的候选组合。比较预测切点与已确认切点的偏差；用户移动过的边界权重为 2，保持原位的边界权重为 1。校准组平均偏差改善至少 20 毫秒，且保留组平均偏差退步不超过 20 毫秒时，才允许应用。
5. 先查看对比报告，再“应用候选参数”。只在单份源素材上校准时会说明没有跨源比较。这些是已有审核样本的匹配统计，不等同于对未来歌曲的质量保证。

参数按歌手保存。应用后重新检查当前数据集任务的边界，不裁切音频、不改变审核决定；新任务记录创建时的参数用于可重复处理。可以“恢复默认参数”或“用当前参数重新检查任务”。反馈或源素材变化后，旧报告不能直接应用。静音质检的绝对阈值仍沿用片段设置；此处校准相对能量阈值。

### 试听缓存

展开“试听缓存”查看当前任务的文件数量和大小。缓存按源文件状态与试听范围复用；最近访问时间会更新。点击“清理过期试听缓存”，默认保留最近访问的 7 天；设置为 0 可清理全部未在当前试听中使用的缓存。清理需等任务结束，会保留当前试听、原始素材、切片修订、修改历史、入库数据和训练文件。兼容清理旧版明确命名的上下文及切点试听文件。

新试听缓存位于任务专用的 `preview-cache`，可随时重新生成。历史修订音频继续保存在 `clips`，用于对比与撤销，不归类为缓存。

数据路径：`svc_data/sources` 保存原文件、人声、伴奏和 LRC；`svc_data/jobs` 保存任务和修订；`svc_data/datasets/<歌手ID>` 累积该歌手已审核片段。显示名称不作为磁盘路径。

## 3. 专属模型训练

1. 选择歌手，确认数据量，再填写实验名、目标步数、batch、保存间隔和 F0 算法。
2. 至少两个已审核片段才允许创建实验；实际训练建议使用多份干净录音覆盖目标音域和唱法。
3. 默认使用兼容的 SVC 专用 G/D 底模。高级区可替换兼容权重；GPT-SoVITS-TTS 的 SoVITS 权重不能用在这里。错误结构会终止并报告，不静默从随机参数开始。
4. 点击“创建快照并开始训练”。创建后的 `svc_experiments/<实验ID>` 保存固定音频、配置、源片段校验值、特征、检查点和日志。之后改审核切片不会修改这个实验。
5. 训练前可查看按总时长推荐的验证源，以及训练/验证片段数、时长和源素材数。展开“各素材时长分配”可查看每份素材的训练与验证时长及总时长占比；手动勾选验证源后立即更新。多份源素材时必须为训练至少保留一份；只有一份源素材时按片段划分，并提示同歌曲验证的限制。
6. 每轮按固定种子打乱训练片段。检查点保存当轮实际样本顺序、批次位置与随机状态；中途续训从下一批继续。旧检查点先按原顺序完成当前轮，之后按轮打乱。
7. 保存 G/D 和优化器状态。停止请求在完整训练步结束后保存续训状态。刷新列表选择实验和检查点。实验会从验证集中固定挑选最多 3 段，优先覆盖不同源录音及音高；选择一段后可并排试听两个检查点与验证原声。点击“A / B 同位置切换”可在同一时间点交替播放，勾选响度匹配时会降低较响一侧的播放音量。旧实验已有的单段试听仍可读取。
8. “从最新检查点续训”追加指定步数。若要使用新追加或重新裁切的素材，创建新实验。

TensorBoard 日志位于实验的 `logs`。固定素材 mel L1 是频谱参考指标，不是音色相似度评分。列表只显示 G/D/优化器状态齐全且已登记保存完成的检查点；新检查点记录大小和 SHA256，提交转换时会再次校验。需要保留的检查点不会被自动删除；实验体积会随保存次数增加。可展开“管理旧检查点”，选择旧步数并勾选确认后手动删除该组权重、状态和试听文件。最新检查点及运行任务使用的检查点不能删除。

任务保存 `metrics.json` 和每次尝试的指标记录，包括处理耗时及 PyTorch CUDA 张量/缓存峰值。这个显存指标不包含 CUDA 驱动上下文，也不是整张显卡的总占用。

### 训练前数据报告

进入“专属模型训练”，在右侧“训练前数据报告”点击生成。报告作为后台任务运行，可在任务历史查看逐片进度、离开页面后返回查看、停止或失败后重试；已完成片段的分析缓存会复用。训练页会在报告区域上方提示完成状态，点击“查看训练前报告”会展开结果。提交期间按钮显示等待状态，同一歌手同时仅运行一项报告分析；相同数据与 F0 已有完整报告时复用已有结果。报告分析当前歌手已经试听审核并入库的片段，使用左侧所选 DIO、Harvest 或 Praat F0，在 SVC 独立环境的 CPU 上运行，不加载训练模型或编码器，也不占用 GPU 排队锁。

- 汇总入库片段数、文件校验有效数、有效时长、源素材数和有声帧比例。
- 音高按半音分桶，仅统计提取器判断为有声的帧，不计入插值补出的无声段。显示中央 90% 音高范围；提取范围沿用当前训练工具的 50–1100 Hz。
- 展示片段长度分布和按有效时长计算的源素材占比，附有明细表。单一源素材、时长范围异常、素材过度集中及文件校验失败会给出提示。
- “建议复核的片段”列出低 F0 有声比例、接近提取上下限、频繁大幅音高跳变、时长异常和文件校验失败的具体片段。选择片段后点击“打开审核试听”可回到原任务。提示只是查找线索，需试听判断。
- 可以下载包含嵌入图表的独立 HTML、完整 JSON、源素材 CSV 和三张 PNG。图表使用英文坐标标签，界面及报告正文提供中文说明。

切换歌手、F0 选择或进入训练页时会读取已有报告，不自动重新分析整套音频。入库清单或文件发生变化后，旧报告显示过期，重新生成才能使用当前统计。分析缓存按音频 SHA256 和 F0 工具复用；缺失、修改过的文件不会计入有效统计，文件修复后也会使旧报告过期。

报告位于 `svc_data/datasets/<歌手ID>/analysis/reports`，后台任务日志在 `svc_data/jobs/<任务ID>/processing.log`。训练页优先显示检查点试听，报告默认收起，按需展开。报告用于判断数据覆盖，不确认歌手身份、伴奏残留、真实音色质量或训练效果，也不会自动选择“最佳模型”。

新增流程的回归验证范围及命令见 [SVC 回归验证](SVC回归验证.md)。

## 4. 完整音频转换

在“完整音频转换”页直接选择目标音色模型。自己训练的模型可选择实验及检查点；现成模型先放入仓库 `svc_imports/<模型文件夹>/`，其中应包含 `config.json` 和生成器 `.pth` 权重，再展开“导入现成 So-VITS-SVC 模型”扫描并导入。导入任务完成后点击“刷新页面数据”，在目标模型列表选择模型及模型内歌手。导入器接受 44.1 kHz 的 ContentVec 第 9 层 256 维或第 12 层 768 维模型；768 维模型还需安装对应编码器，可运行 `python -m tools.svc.install --skip-pip --with-vec768`。导入时校验权重结构，不兼容的模型会说明原因。导入模型会复制为独立快照，避免原文件后续变动影响转换。

如需浅扩散细化，请在同一模型文件夹放入 `diffusion/model_30000.pt`、`diffusion/config.yaml`、`diffusion/vocoder/model` 和 `diffusion/vocoder/config.json`。四个文件须齐全且与基础模型匹配；推理前会校验快照文件。选择带浅扩散的导入模型后，可在转换页开启“使用浅扩散细化音色”并设置步数，默认 35 步。关闭后仍可使用基础生成器，以同一素材对比效果。浅扩散可能减少部分电子音，但会增加处理时间，效果依素材而异。若包内配置的时间步数与权重不一致，以权重保存的调度长度为上限。

输入可上传音频或直接录音。录音支持说话降噪、清唱保留原声，以及带伴奏唱歌后分离人声；录音控件可先试听并重录。降噪使用项目的语音降噪模型，首次处理时可能下载模型；唱歌带伴奏时使用 UVR5 分离。分离可能改变音色，结果仍需试听。上传音频支持干净人声、带伴奏音乐自动分离，或分别上传已分离的人声与对应伴奏。最后一种方式跳过自动处理，转换后按原时间轴混音；两份音轨应从同一时间点开始，时长差最多 0.1 秒，解码后仅裁掉或补齐短尾部，不做自动对齐。调整半音偏移、F0 和内部分段长度后提交。录音默认只输出转换人声；上传的伴奏仅在选择混音输入时保留并提供混音结果。

转换使用源内容及源 F0，不默认重预测旋律。分段使用上下文及交叠渐变，按原采样位置拼接，保留静音和总样本数。混音保留原伴奏，严格按设定增益相加，不自动归一化、衰减或限幅；导出浮点 WAV 保留超满刻度幅度，超过 0 dBFS 时在波形下方提示，由用户手动调整。可单独下载转换人声、混音和伴奏。提交转换后，后台任务会逐块校验检查点并在任务状态显示已校验数据量；此时可以请求停止。失败或停止后重试同一任务时，会逐块校验源文件、解码音轨以及已分离的人声/伴奏的 SHA256、大小和帧数，并显示进度；验证通过的阶段直接复用，损坏或不完整的阶段重新处理。

### 主唱与和声分轨

歌声转换默认开启“分离主唱和和声”，说话录音自动跳过。无和声的清唱或上传的说话音频可关闭该选项，沿用整条人声转换。处理顺序为：人声 / 伴奏分离（或使用上传的独立音轨）→ 全部人声拆为主唱 / 和声 → 按所选方式转换 → 合并人声，按输入设置与伴奏混音。

提供三种方式：

- **仅转换主唱，保留原和声**（默认）：主唱替换为目标音色，和声沿用分离结果。
- **主唱与和声分别转换**：分别提取两条音轨的 F0，使用同一目标音色独立转换，再合并。
- **仅保留转换主唱**：不把和声加入最终人声，分离和声仍可试听和下载。

“分段与混音”可设置和声增益，以及转换和声时的额外半音偏移。额外偏移叠加在主唱音高偏移上，默认 0；各声部按设定增益保留原幅度，不因其他声部或混音超满刻度而自动变小。所有分离、转换和混音音轨都保留原始样本数与静音位置。

在“分离模型”中分别选择两阶段模型，新任务默认使用：

- **人声 / 伴奏：**[Mel-Band RoFormer Deux](https://huggingface.co/becruily/mel-band-roformer-deux)，固定修订 `402dd9a19baaed8c6f1b54458ce6ae2ae19f354e`，权重约 435 MB。直接输出全部人声和伴奏；素材准备与完整音频转换使用相同入口。干净人声、清唱录音及单独提供伴奏的情况跳过伴奏分离。
- **主唱 / 和声：**[BS-RoFormer Karaoke · frazer / becruily](https://huggingface.co/becruily/bs-roformer-karaoke)，固定修订 `f7849ae934209184dc288d1018cd8a76a7fc8b3c`，权重约 204 MB。先从全部人声估计主唱，以全部人声减去主唱得到和声轨；和声可能包含串音、分离残留及多个声部。

模型按作者配置推理，Deux 的窗口为 13 秒、重叠 2 倍，BS Karaoke 的窗口为 20 秒、重叠 4 倍。长音频保留上下文、交叠拼接并按原样本数写出，不移动音轨时间轴。首次使用自动下载并校验 SHA256，可提前执行 `python -m tools.svc.install --skip-pip --skip-models --with-separation`。权重、配置及来源记录保存在 `runtime/svc-assets/separation/`；已安装且校验通过时不需要联网。

旧版 **HP2** 和 **Mel-Band Karaoke · becruily** 仍可选。后者的固定修订为 `0c149975cfaa261c7d87baf54330a9da85bcf888`，约 1.7 GB，保存在 `runtime/svc-assets/vocal_split/`，旧安装参数 `--with-vocal-split` 保留。旧任务和文件不会自动重做；没有模型字段的历史任务按旧模型解释。旧转换任务打开“重试 / 调整配置”时会推荐新模型，可改回旧模型对比。改变任一分离模型会使对应缓存失效，第一阶段更换后也会重新拆主唱和和声；输入解码及匹配的阶段继续复用。任务详情展示所选分离模型，新模型任务目录另存 `separation-models.json` 来源记录。

MVSep BS-RoFormer 124 bands（2026.10）在官方平台目前限付费用户使用，官方 API 可选择 Karaoke 模型 8（`sep_type=49`、`add_opt1=8`）。截至 2026-10-19 未找到公开本地权重，本地选项不冒用此名称；当前没有调用 MVSep API 或上传音频。参见 [官方发布说明](https://mvsep.com/en)及 [API 文档](https://mvsep.com/en/full_api)。

分离结果仍可能有串音或漏唱，和声音轨也可能同时包含多个声部，当前单 F0 的 SVC 无法保证把复杂和声完整替换。可先用默认方式试听主唱，确认后再尝试和声转换。

任务中心分别展示合并后人声、最终混音、分离主唱、分离和声、伴奏、转换后主唱、转换后和声以及全部人声，存在的音轨均可下载。分离完成后即可试听，不必等转换结束；轮询不反复重载未变化的播放器。旧任务保留已有音轨，未做主唱 / 和声拆分的任务不会凭空显示分轨。可在“重试 / 调整配置”选择新的处理方式创建新任务；原任务与结果保留。新任务会复制前次中间音轨并逐块校验，完整且匹配的分离阶段复用，缺失、损坏或版本变化时重新处理。

完整音轨保留波形图、播放进度高亮和波形定位，可用鼠标、触摸或键盘调整播放位置。服务器在后台逐块生成小体积波形缓存，浏览器只读取波形数据，不同时下载并解码所有完整音轨；旧任务首次查看时自动补齐缓存。点击播放或定位时才加载音频。切换任务会取消旧波形请求并停止、释放旧播放器，播放另一条音轨时会暂停前一条；单条音轨加载失败可独立重新加载。下载提供原始输出文件。素材审核页的短片段波形播放器不受影响。

听起来跑调严重时，先试听分离主唱本身是否已失真，再在重试设置中对比 DIO、Harvest 或 Praat；音高提取方法可能造成八度错误或断续，分离伪影也可能干扰 F0。

长音频逐块读取、转换和写出，拼接缓存只保留当前分段与交叠尾部。混音也逐块处理，使用整条音轨的峰值统一缩放，避免每块音量跳变。为此会在任务目录临时写入浮点音轨，增加磁盘读写与临时空间需求；正常完成、异常或协作停止时清理临时目录。强制杀进程或断电时可能留下临时目录，先确认任务已停止再清理。

素材整理同样逐块读取源音频，保留约每 20 毫秒一个值的能量曲线用于全局停顿规划。该曲线和切片元数据随音轨长度增长，但不会把整段原始人声音轨一次载入内存。每个候选切片仍独立进行工具检查与试听审核。

歌声优先；仅歌声训练的模型对说话的效果需另行试听。当前工作台不包含实时变声、角色混合、多人合唱歌手分离或拖动波形边界；边界编辑使用精确时间控件。

## 任务与设备

界面校验失败时用右上角通知提示，约 5 秒后自动消失，保留已填内容，不把关联控件替换为 Error。名称无效时显示红色输入边框及说明，重新输入后清除。自动刷新遇到读取错误会暂停，在任务状态显示原因，可点击“刷新列表”重试。

任务历史和状态位于操作区上方。任务完成、停止、失败或等待试听后停止自动轮询；需要重新查看检查点或记录时点击“刷新列表”。歌词时间定位、片段列表和边界修正区域默认折叠，可按需展开。

任务以独立子进程运行，历史记录支持刷新页面后恢复。SVC 任务共享 `output/auto_dataset-gpu.lock` 排队运行；TTS 模型加载和合成也使用该锁，主界面的训练及预处理启动检查会识别 SVC 队列。已运行的 TTS 训练/预处理应结束后再提交 SVC 任务。

TTS 推理模型加载后即使没有合成，也会驻留显存。提交 SVC 前请在“TTS 推理”点击“卸载模型”；界面会对此提示并保留输入，不自动卸载用户已选模型。

GPU 编号沿用现有逻辑设备映射。停止为协作取消：解码可中断，分离和推理在当前块结束后停止，训练在当前步结束后停止。异常退出可重试；成功处理的源素材及成功保存的训练状态会继续使用。

需要把数据放在其他磁盘时，可在启动前设置 `GPT_SOVITS_SVC_DATA` 和 `GPT_SOVITS_SVC_EXPERIMENTS` 为绝对目录；后台子进程会继承这两个目录设置。

界面显示素材任务与训练实验所在磁盘的可用空间，点击“刷新列表”更新。上传归档、创建快照、音轨处理与检查点保存增加空间检查；默认另外保留 2 GiB，可用 `GPT_SOVITS_DISK_RESERVE_GIB` 调整。转换按解码音轨估算临时空间，检查点保存按 G/D 与优化器张量估算整组空间。估算不能独占磁盘或涵盖首次模型下载，实际需求可能更大。

空间不足时任务停止并显示原因，释放空间后可以重试或从最近完整检查点续训。原始素材、入库数据、实验快照、已有检查点及续训状态继续保留，不自动删除；尚未成功保存的训练步可能需要重做。

### 可选输入去混响（转换与训练素材）

使用本地立体声 **BS-RoFormer De-Reverb · anvuew**。默认关闭；可按轨开启。处理顺序：Deux 提取全部人声 → BS Karaoke 分离主唱 / 和声 → 两轨分别按需去混响 → SVC 转换或训练候选切片。未开启主唱 / 和声拆分时，“主唱／未分轨人声去混响”处理全部人声；和声开关仅分轨后使用。此功能估计较干的人声，不承诺恢复录音原始干音，也不会给转换结果添加混响。

- **完整音频转换 → 输入去混响（可选）**：主唱、和声两个独立开关。在保留原和声模式，勾选和声去混响后，合并的是处理后的和声；仅保留主唱模式不会将和声混回。重试配置也可修改两个开关，原任务不受影响。
- **素材与审核 → 主唱 / 和声与去混响（可选）**：可开启主唱 / 和声拆分，默认仅主唱生成候选切片。勾选“和声也生成候选切片”后，和声以独立素材进入同一歌手的审核列表，不会自动入库或另建模型。和声须属于目标歌手且为单声部；多声部叠唱、其他歌手或分离伪影应排除。
- **任务中心**：保留分离原音轨，另列去混响主唱、去混响和声（未拆分时为去混响全部人声），以及移除的混响与残留，均支持缓存波形、试听与下载。训练素材批次可通过“试听素材”切换歌曲。残留轨也可能包含被误删的人声，不会自动混回。
- **审核与训练**：切片标记其主唱 / 和声类别及准确来源；修改边界、拆分合并、反馈校准均继续使用同一来源音轨，禁止跨音轨合并。同一歌曲的主唱 / 和声共享原素材编号，训练 / 验证按原素材分组，避免跨集合泄漏。
- **缓存与时间轴**：去混响的双声道采样率保持 44.1 kHz，样本数与输入相同。原轨不覆盖；处理对以源 SHA256、模型版本、配置签名和输出指纹校验后提交。转换重试可复用匹配的去混响阶段；变更分离模型或输入时重新处理。

混响较重时可开启，原本较干的音轨建议先关闭。处理可能损伤齿音、气声和尾音，尤其是和声，需要试听对比；这一步增加推理时间与保存音轨的空间。

模型来源：[anvuew/dereverb_bs_roformer](https://huggingface.co/anvuew/dereverb_bs_roformer)，仓库标注 GPL-3.0。固定版本 `bd5c6b55a429b4b74ce85fe5dcb690cfe36d91ec`，文件 `dereverb_bs_roformer_anvuew_sdr_22.5050.ckpt`，大小 204,496,717 字节，SHA256 `b4dfa4c4aa251c0afc303e5d512d904a1c2255e51d8d0dbfbddb18d740563d42`。采用作者配置的 448000 样本窗口、2 倍重叠及立体声模型；配置随代码保存在 `tools/svc/model_configs/dereverb.json`。安装参数：`python -m tools.svc.install --skip-pip --skip-models --with-dereverb`。运行时仅下载模型，音频在本机处理。

### 神经音高、相位检查与参考音准校准

- 训练 F0、转换 F0、训练前数据报告均支持 **RMVPE / FCPE**，保留 DIO / Harvest / PM。新转换默认选择 RMVPE；历史任务重试沿用原方法。RMVPE 固定 RVC 权重版本 `e6d0c1a17da07c33557852f9dfa2bd44cc75737d`，SHA256 `6d62215f4306e3ca278246188607209f09af3dc77ed4232efdd069798c4ec193`；FCPE 固定 `torchfcpe==0.0.4`，随包权重 SHA256 `b9aeaeb673436eeda50ceafd632aa681aa63417e52eae4207503d180c9b10015`。首次安装可运行 `python -m tools.svc.install --skip-pip --skip-models --with-pitch`，新环境先安装 `requirements-svc.txt`。
- 转换前按整轨时间网格分析 F0（长文件分块且保留上下文），缓存键包含源 SHA256、方法、模型、采样率、帧步长和声道选择。静音与无声区域独立保存，不能把为合成而插值的 F0 当成实际演唱。每次任务在 `channel-analysis.json` 记录各输入轨声道检查。
- 双声道直接取平均可能抵消反相成分。检查在活跃的 0.1 秒窗口比较左右与中间声道能量，并记录整体相关性、中间声道能量变化及疑似抵消窗口占比。有明显风险时，整轨统一选择能量较高的左或右声道供音高和内容分析，避免逐帧切换声道；原立体声音轨保留。这不能把多声部和声变成单声部，也不代表抵消一定是跑调原因。
- **任务中心 → 参考原轨的音准分析与一键校准**：选择已完成的转换任务，先用“仅生成音准偏差报告”，再选 PSOLA、PC-NSF 或同时生成两版。处理为独立后台任务，不需要重复跑 SVC，原任务保留。主唱参考原主唱，转换后的和声参考原和声，优先使用实际输入 SVC 的去混响音轨；未拆分时比较整条人声。主动移调、和声额外移调均计入参考目标。
- 报告按连续音高比较，显示有效可比帧、绝对偏差中位数、P95、疑似八度偏差、异常区间及音高曲线，提供 JSON 下载。RMVPE 与 FCPE 交叉检查前后音轨；结果是算法测量，气声、复音、残留或分离失真会降低可靠性。最多估计约 ±46 毫秒局部固定测量延迟，不移动或拉伸输出音轨。
- 校准默认阈值 50 音分（100 音分为半音），只处理可信的持续偏差，保护无声与原本正确的区域。保留原演唱的连续滑音、颤音；不向十二平均律音符网格强制吸附。声码器分块推理保留上下文，修音结果按原样本数写出，并局部交叉淡化。校准后复测，检测指标变差或有声判定不可靠的区间跳过；这不能保证修复所有跑调或消除所有伪影。
- **PSOLA** 使用项目已有 Praat / parselmouth，无需独立 GUI。**PC-NSF-HiFiGAN** 使用 OpenVPI 官方 2025.02 OpenUTAU ONNX 包，44.1 kHz / hop512 / FFT2048 / 128 mel / Slaney / 40–16000 Hz / 自然对数。可运行 `python -m tools.svc.install --skip-pip --skip-models --with-pitch-correction`。官方包 SHA256 `ba7d43142d41f6900c8264b5662ca7125a50feb8760bb8b9615c61a8f5e6902e`，权重许可 CC-BY-NC-SA-4.0，来源和文件指纹保存在 `runtime/svc-assets/pitch/pc_nsf/manifest.json`。
- 两后端输出分别展示、试听、下载；按原任务主唱 / 和声模式重新合并及混伴奏。保留原和声模式不修其音准；只保留主唱模式不混回和声。检测依据不充分时输出可能与原转换一致，报告会提示。音频全部在本机处理。

### 独立「一键校准」工作区

左侧导航新增 **一键校准**，可以直接上传两份音频，无需先完成 SVC 转换：

1. 上传参考音频与待校准音频，分别选择“纯人声”或“带伴奏音乐”。每份音频最长 20 分钟。
2. 选择仅校准主唱并保留原和声、主唱 / 和声分别校准，或单声部人声直接校准。带伴奏输入先用所选人声分离模型处理；拆分声部时再使用 Karaoke 模型。仅校准主唱时保留目标原和声的立体声；直接校准适合已分好的单声部音轨。
3. 默认使用 PSOLA，可切换 PC-NSF、两版对比或仅生成报告。参考与目标可分别选择去混响，默认均关闭。
4. 独立演唱默认选择“同曲自动对齐”：用现有 ContentVec 内容特征匹配对应演唱段落，DTW 矩阵最多 3000 × 3000，匹配不可靠的区间跳过；匹配整体不足则提示失败。算法仅将参考音高映射到目标时间轴，输出音频不拉伸。参考更长时支持子段落匹配；仍需上传同曲、对应段落，无法保证复杂删节、反复重排的自动匹配。
5. 对于已有相同时间轴的 SVC 前后音轨，可选“按原时间轴”；参考时间偏移为正时，从参考的更后位置开始取音高。参考音高偏移用于不同调的对应演唱。
6. 任务与输入持久保存，离开页面后后台继续执行。右侧可以选择历史校准任务、停止、按原配置重试，并查看报告、原始上传、人声、校准音轨的波形与试听下载。带伴奏的目标会将校准后人声混回目标自己的伴奏；参考伴奏不会混入结果。任务也可在 SVC 任务中心查看。

原始参考与目标均保留；参考原轨可与目标有不同长度，报告中的参考音高曲线已映射到目标时间轴。主唱 / 和声分别处理时，仍仅适用于能可靠提取音高的单声部内容，复杂叠唱或低匹配区间可能保持原样。新页面复用已安装的 RMVPE、FCPE、分离模型和两种修音后端。

### 输出混响 · 参考原曲（可选）

在 **完整音频转换 → 输出混响（可选）** 中开启“转换后自动添加混响”，默认关闭。可选择参考原曲估计或手动混响，分别设置主唱、转换和声的强度；高级参数在开启后展开。混响在 SVC 转换之后、同一个转换任务内自动执行，无需在任务中心另行提交。结果在任务中心展示、试听和下载；原转换及干声结果保留。训练实验模型与外部导入模型均支持，转换重试沿用已保存的输出混响配置。任务中心已移除独立混响提交入口，历史混响任务仍可查看结果及按原配置重试。

**一键校准 → 进度与结果** 仍提供对已完成校准结果单独添加混响的入口，支持 PSOLA / PC-NSF，不必重新修音。已有混响任务再次提交时从原任务重新处理，避免反复叠加。

- 支持 SVC、PSOLA、PC-NSF 结果；自动选择在校准任务中优先使用 PSOLA。仅生成音准报告的任务须先生成校准结果。
- “参考原曲估计混响”分别分析主唱、和声的原曲湿声与去混响估计，近似计算混响量、尾音衰减、频率阻尼与立体声宽度，然后合成全新的立体声脉冲响应并分块卷积生成的人声。已有参考干声直接复用，否则使用已安装的 BS-RoFormer De-Reverb 生成参考干声估计。独立上传校准使用上传的**参考演唱**估计空间感，仍混回目标自己的伴奏。
- 参考波形和去混响残留只用于估计参数，**不作为混响音轨混回**，避免引入原歌手声音。模型分离误差、叠唱、延迟、调制及自动化效果使估计无法精确还原原曲混音；报告显示可信度、可用尾音数和回退说明。
- 支持手动混响，并可单独调整主唱／生成和声的强度。衰减范围 0.3–4 秒，预延迟 0–120 毫秒，混响／干声幅度比 0–0.65。参考模式无法可靠识别预延迟，始终沿用手动值；缺少清晰尾音时衰减使用手动回退，参考干湿差异过大时采用手动参数回退。手动参数不是对真实房间的测量。
- 较干的 SVC 输出通常直接加混响即可；输出本身已有明显混响时，可勾选“先对待处理人声去混响”。这会增加时间，也可能损伤气声和尾音。主唱、和声仅处理实际生成的轨；保留原和声时原样加入并沿用增益，不重复加混响。
- 新任务展示**加混响后的主唱、和声、合并人声、完整混音**及处理前版本、参考轨、原伴奏；只显示实际存在的音轨。未拆分声部的任务将整条人声作为主唱／人声处理，不会凭空产生独立和声。有对应伴奏时会生成“带混响主唱 + 和声 + 原伴奏”的完整混音；纯人声没有伴奏时不生成这一版。历史校准任务若未登记伴奏路径，会回溯原转换任务的伴奏，后续校准任务直接保存伴奏路径。波形采用原有缓存与按需加载播放器，并可下载混响参数 JSON。
- 输出为 44.1 kHz 立体声，保持目标的样本数与干声起点；超出原曲结尾的混响尾音不导出。各生成人声与完整混音均保留设定幅度，浮点 WAV 不自动衰减或限幅；超过 0 dBFS 时播放可能失真，可手动调低增益。处理为后台可取消任务，参考分析使用现有 GPU 队列，卷积与参数拟合在 CPU 上执行，音频不上传外部服务。无需安装新的效果器依赖。

“混响参考完整混音”展示用于参考混响的原曲完整音频（原主唱 + 原和声 + 原伴奏），可与“加混响后完整混音”对比试听、下载。独立上传校准使用上传的参考歌曲；人声和伴奏分别上传时，将原人声与对应伴奏按原时间轴原幅度合并，不自动降低音量。纯人声参考没有伴奏时，不显示完整混音；已有转换或校准后的混音仍单独作为“加混响前完整混音”保留。

### 任务中心：生成后编辑增益与混响

选择已完成的音色转换、校准或历史混响任务，展开 **生成后编辑 · 增益与混响**。

- 主唱／人声、和声可以分别调整加混响前与加混响后的增益，伴奏有独立增益。范围为 -60 至 +12 dB，0 dB 表示相对最初音轨不增加额外增益；没有对应音轨的控件隐藏。保留的原和声也可调整增益，混音沿用原任务的人声／伴奏与和声比例。
- 点击 **确认保存增益与混响，并刷新音频**，在原任务内启动 CPU 后期编辑，不新增任务编号，不重复 SVC、分离或音准校准。干声分轨重建干声合并人声与完整混音，湿声分轨重建带混响人声与完整混音，伴奏同时参与两类混音。PSOLA / PC-NSF 同任务的多个版本同步使用这组增益，分别合成结果。
- 勾选 **重建输出混响** 可添加或修改主唱／生成和声的混响强度、衰减、预延迟与混响／干声幅度比。从备份的生成干声重建，已有参考混响的频率阻尼和空间宽度保留，没有既有混响时采用默认空间参数。不重新估计参考混响或去混响；原输出已启用生成干声去混响时，复用该干声缓存。保留的原和声不重复加混响。关闭此开关则使用最初生成的混响轨。
- 每次保存都相对首次备份计算，避免增益或混响反复累加。首次保存备份原始生成分轨，后续使用版本目录，成功后一次性替换任务的输出路径；播放与缓存波形自动刷新，原曲参考、源分离音轨保持原样。失败或停止时继续展示上一次完整保存的音频，点击 **恢复最初音频** 可以恢复原输出及 0 dB 编辑设置。
- 各导出分轨和混音均按设定增益保存，不自动衰减、归一化或限幅。伴奏设为 0 dB 时保持最初幅度，不受人声增益影响。浮点 WAV 保留超过 0 dBFS 的数值，报告逐项显示过载输出及峰值；播放可能失真，由用户手动决定是否降低增益。各轨继续保持原采样率和样本数。旧版已保存的整体衰减仍属历史结果，重新保存会从最初备份按新规则计算。
- 保存可以在后台继续，允许切换任务，不会强制重新加载未变化的音轨。保存期间阻止删除、重试同一任务；可用 **停止本次编辑** 或任务的停止按钮取消。页面重启后可恢复编辑状态，后台意外退出会提示重新保存。首次备份及每次保存会占用额外磁盘空间，保存前与写入时检查余量。

### 统一 dBFS 波形与单轨视图

任务中心表格增加“参考音频”和“音色模型”两列，可按歌曲名或模型名搜索；转换重试、关联校准和混响任务继承原始名称。新上传自动保存客户端原文件名，录音使用带日期时间的名称。未保存原名的历史转换任务明确显示“未保存原文件名”，可补齐后用于表格和下载命名。

列表、集中下载和单轨视图的“下载音轨”入口统一打开格式弹窗，可选 **WAV** 或 **MP3（320 kbps）**。WAV 原文件直接下载并显示准确大小；MP3 未生成时明确显示预估大小，确认后在后台按需生成，完成后更新为实际大小并开始下载。重复下载复用对应版本的缓存，不新建任务，也不阻塞页面试听。下载文件名为 **音色模型_原上传音频名_原音轨文件名.wav/mp3**，移除原上传文件的扩展名，并处理文件名非法字符与过长名称。WAV 保留原始浮点幅度，MP3 不添加自动增益或限幅，但有损编码与播放的结果可能失真。生成后编辑更新输出路径时，下载弹窗校验版本，避免误下载已变化的音轨。

音轨按可折叠分类展示：**生成结果、原曲参考、伴奏、处理过程与历史对照**。生成结果继续区分带伴奏完整混音、加混响前人声与加混响后人声；原曲参考区分完整音频与参考人声；处理过程收纳转换／校准前音频、去混响输入、移除残留以及输出混响前的输入快照。默认展开生成结果中的完整混音，其他分组可按需展开；空分组自动隐藏，标题显示去重后的音轨数量。集中下载入口默认折叠，也按相同分类排列。

相同文件或采样内容完全相同的音频只展示和下载一次，其他名称列在保留的音轨下。后台随波形缓存生成解码后采样指纹，比较采样率、声道数、帧数及逐个 float64 采样；文件名、容器或 WAV 头不同但采样相同也可合并。不依据相似波形或接近的峰值判断相同，因此音量、混响或编辑版本不同的音频保留。旧任务首次查看时随缓存生成逐步合并重复展示，不同步扫描整首音频阻塞任务切换，也不删除底层文件或影响恢复最初结果。

“完整混音 · 加混响前”是当前输出；“加混响前完整混音 · 输入快照”是添加输出混响时保存的输入。未编辑且内容相同时会合并展示；增益编辑后两者可能不同，此时快照保留在历史对照分类，可作为编辑前对比，不冒充当前混音。

任务中心和独立校准页面的波形使用统一的绝对幅度基准：0 dBFS 对应数字满刻度，概览不再将每条音轨各自除以自身峰值。小音量音轨会显示为更小的波形。列表顶部只显示一次公共幅度说明，不再在每条音轨左上角重复刻度数字。每轨右侧增加当前位置窗口电平表，彩色柱为峰值、白线为 RMS，范围 −60 至 0 dBFS，数值仍显示超出范围的电平。播放或定位时按需读取详细包络，按所有声道计算并标注窗口时长。每轨下方另列整轨峰值和 RMS（以所有声道的采样能量计算）；静音显示为 −∞ dBFS。浮点音轨峰值超过 0 dBFS 时，数值保留，概览绘制限于满刻度范围。

点击音轨标题打开全屏 **单轨波形视图**，返回按钮或 Esc 关闭，返回时保留试听定位。支持：

- 左右声道分开显示（单声道显示 Mono），横轴时间、纵轴 dBFS。整轨与各窗口的峰值 / RMS 分别标注。
- 按钮或滚轮横向缩放，Shift＋滚轮平移；底部滑块、左右按钮移动时间视窗。点击波形定位，拖动选择片段后可“放大选区”，也可切换为直接拖动平移。
- 纵向显示放大 -12 至 +36 dB，坐标值随显示比例更新，只用于观察；实际音频增益仍由生成后编辑的保存操作修改。
- 全曲使用缓存的分声道正负包络；放大后按需通过 HTTP Range 读取当前 PCM WAV 片段，单次最多 8 MiB，可细看采样点之间的波形。没有可读取 PCM 布局的格式保留包络视图，并限制最大缩放，避免把缓存插值当成真实采样。
- 窗口电平优先使用约 10 ms 采样片段，否则使用缓存包络对应区间并标明窗口时长。此处是数字幅度 / RMS，不是 LUFS 响度或声压测量。
- 键盘可在波形区域使用空格播放 / 暂停、＋／− 缩放、0 适应全曲、左右键平移。提供等效按钮，窄屏下工具栏换行。只在播放、定位或打开单轨视图时读取详细数据，不一次解码所有音轨或整首歌曲。单轨右侧另有带 dBFS 刻度的电平表。服务重新部署后若旧标签页收到新版音轨 HTML，会显示刷新提示，刷新加载新脚本后再打开单轨。
