# SVC 回归验证

本轮验证（2026-10-14）使用临时目录中的可控合成 WAV。自动测试实际执行 FFmpeg 解码、切片及文件读写，以及隔离 SVC 环境中的 DIO、Harvest 和 Praat F0。此前用临时合成数据做过一次两步 GPU 训练与续训冒烟检查；本轮没有重复 GPU 模型训练。验证均不修改用户歌手素材、入库数据或已有实验。

## 执行

在主工作台环境中运行：

```bash
python -m unittest discover -s tests -v
```

需已安装 SVC 独立环境和 FFmpeg。测试报告生成会通过 `runtime/svc-env/bin/python` 使用已有的 F0、Matplotlib、NumPy 和 SoundFile；测试记录、图表和缓存均写入临时目录。

## 覆盖范围

| 范围 | 验证内容 |
| --- | --- |
| 连续撤销 | 多次修改、多次回退、新分支修订不覆盖历史音频 |
| 拆分与合并 | 拆分后合并，撤销合并和拆分后恢复原片段编号及波形校验值 |
| 共用切点 | 推荐移动时同步调整两侧，保持总样本覆盖与共同边界；撤销可恢复 |
| 过期操作 | 旧推荐或不匹配的撤销状态不会覆盖当前记录 |
| 数据发布 | 撤销后撤下受影响的未来训练清单，已创建实验快照保持原文件内容 |
| 反馈校准 | 只有确认后的边界成为标签；撤销、恢复待审核及源文件变化使标签失效；独立源保留组与参数应用路径 |
| 试听缓存 | 重用、过期清理、当前试听保护、切片与历史修订保护、损坏索引恢复和未知文件保留 |
| 界面回调 | 实际 Gradio 连续审核、撤销、修订对比和报告回调的输出数量与后处理；报告过期后清空旧统计 |
| 数据报告 | 有效文件统计、时长加权源占比、长度分桶、无声和非有限 F0 排除、真实三种 F0 提取器 |
| 报告存储 | 独立 HTML 与图表、JSON/CSV、片段分析缓存、旧报告保留、清单变化及文件删除／修复后的过期检测 |
| 训练顺序 | 每轮打乱、检查点保留实际顺序、从保存批次继续、旧检查点当前轮按原序完成 |
| 检查点比较 | 固定验证片段按源和 F0 分散选择；同一片段在两个检查点间试听，Gradio 音频后处理 |
| 报告定位 | 指出低有声比例、F0 范围边缘、频繁跳变及短片段，并打开对应原审核任务 |
| 后台报告 | Worker 停止请求、真实隔离子进程重试完成、损坏分析缓存重建、同一歌手并发提交去重、已有有效结果复用 |
| 转换缓存 | 真实 FFmpeg 解码、阶段复用、音轨损坏和状态 JSON 损坏后的重建；分离步骤以可控替身代替模型 |
| 校验与清理 | 大文件 SHA256 中途停止、检查点完整组保护、转换 Worker 拒绝同大小但校验值错误的权重、旧检查点及试听文件清理 |
| 验证集交互 | 手动指定源素材、各源时长占比展示、Gradio 回调后处理、训练快照持久化所选源 |

本轮整仓自动回归共 65 项通过。此前 GPU 冒烟检查在临时目录建立 4 段合成音频，完成特征提取、1 步训练、保存、2 段固定验证试听，然后续训到第 2 步；续训保留相同的当轮样本顺序，并生成第 2 步试听。

## 已修复问题

校准统计中累加 NumPy 布尔值会得到 NumPy 整数，导致 JSON 保存失败。现将边界误差和命中计数转换为 Python 标量，完整校准、保存及应用路径已加入回归检查。

## 验证边界

Gradio 检查覆盖真实组件构建、回调和输出后处理，没有执行浏览器点击、播放器听感或快捷键的浏览器自动化。转换缓存复用检查使用真实 FFmpeg，但用可控音轨代替 UVR 模型分离；检查点完整性测试未执行整条模型推理。此前 GPU 冒烟训练只证明短流程可以完成，没有进行真实歌声断句评分或音色效果评测。合成音频不能代替用户素材试听。
